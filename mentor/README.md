# Наставник курса для Claude Code

Навык Claude Code, который проверяет практику дня курса «Вайб-кодинг на практике» в проекте приложения: `/mentor 1` — проверить день 1.

## Установка

Скопируйте эту папку в проект приложения как `.claude/skills/mentor` (это шаг практики дня 1 — запрос для агента есть на странице дня).

## Что внутри

- `SKILL.md` — инструкция наставнику: прочитать чек-лист дня, проверить пункты, задать вопросы, записать итог в `mentor-log.md`.
- `days/day-NN.md` — чек-листы готовых дней. Они генерируются из файлов курса, руками их не правят:

```
cd course && npm run build:mentor
```
