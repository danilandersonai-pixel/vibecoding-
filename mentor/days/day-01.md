# День 1 — Азбука и знакомство с моделями

**Цель:** Понять, из чего состоит приложение, какие бывают режимы работы с ИИ и как выбрать модель

**Результат дня:** Настроены Claude Code и GitHub, создан репозиторий приложения для тренера с CLAUDE.md и описанием идеи, установлен наставник

## Чек-лист

- [ ] В репозитории есть хотя бы один коммит
- [ ] CLAUDE.md существует, называет цель и стек и содержит запреты [auto: file]
- [ ] docs/idea.md отвечает: для кого, какая задача, чем отличается [auto: file]

## Вопросы автору

1. Что в вашем CLAUDE.md агенту делать запрещено и почему?
2. Какую модель вы взяли для планирования, а какую для повседневной работы и почему?

## Практика дня: критерии «готово»

- Установить Claude Code и войти — готово, когда: Команда claude открывается и показывает приветствие, вход выполнен (Claude Code работает на тарифе Pro и выше).
- Создать приватный репозиторий trainer-app на GitHub — готово, когда: На github.com есть приватный trainer-app, а у вас на компьютере — его папка.
- Открыть проект в Claude Code — готово, когда: Claude Code запущен в папке trainer-app (окружение Local) и описал её содержимое.
- Описать идею в docs/idea.md — готово, когда: В docs/idea.md два абзаца: для кого, какая задача и чем отличается; файл в коммите.
- Запустить /init и дополнить CLAUDE.md — готово, когда: CLAUDE.md называет цель и стек и содержит три запрета; изменения в коммите.
- Установить наставника и запустить /mentor 1 — готово, когда: Папка .claude/skills/mentor в коммите, команда /mentor 1 запускается и проверяет день 1.
