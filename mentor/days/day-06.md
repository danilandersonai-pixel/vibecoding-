# День 6 — График прогресса и безопасность

**Цель:** Показать тренеру график прогресса, провести аудит безопасности и бережно обращаться с данными о здоровье

**Результат дня:** Есть график прогресса и сканер секретов перед коммитом; аудит проведён, запросы без склейки, в журналах только id и время, лицензии пакетов проверены — всё в коммитах

## Чек-лист

- [ ] В git нет .env-файлов, в коде нет ключей и паролей; NEXT_PUBLIC_ — только у адреса и публичного ключа Supabase; сканер секретов стоит перед коммитом [auto: secrets]
- [ ] npm test зелёный: тест на чужие данные на месте, и без входа он получает пусто; исправления дня закрыты тестами [auto: tests]
- [ ] Чужой график: войти тестовым тренером Б (почта и пароль — в .env.test.local), открыть /clients/<номер подопечного тренера А> — ни карточки, ни графика; без входа /clients/<номер> ведёт на /login [auto: rls]
- [ ] В журналах приложения нет имён, почты и заметок подопечных — только id и время; персональные данные без основания и нужды не уходят во внешние ИИ-сервисы
- [ ] У коммита с правками журнала — строка Co-Authored-By; спорные лицензии из сводки автор называет, объясняет, чем копилефт опасен для закрытого приложения, и знает, что сводка пакетов не ловит чужие фрагменты в его коде

## Вопросы автору

1. Какую находку аудита вы проверили руками, что увидели и что с ней сделали?
2. Где в вашем коде запрос к базе мог бы склеиться из ввода пользователя и что там стоит вместо склейки?
3. Что ваше приложение пишет в журнал при сохранении подхода и почему там нет имени и заметки?

## Практика дня: критерии «готово»

- График прогресса подопечного — готово, когда: Вы вошли подопечным и тренером А — у каждого свой график; тренер Б на карточке подопечного А не видит ничего.
- Аудит безопасности — только отчёт, в режиме Plan (в терминале — Shift + Tab) — готово, когда: Отчёт по каждой угрозе; самую серьёзную находку вы проверили руками; правки вы не разрешили, git status чистый.
- Сканер секретов перед коммитом — готово, когда: Сканер поймал пробный ключ и остановил коммит; пробный файл удалён, хук сканера — в коммите.
- Параметры вместо склейки строк, без входа — отказ — готово, когда: Без входа /clients ведёт на /login, действия отказывают; склейку агент исправил с тестом или объяснил, почему её нет.
- Данные о здоровье: в журналах только id и время — готово, когда: Вы сохранили подход: в терминале с npm run dev нет имени, почты и заметок — только id и время.
- Лицензии зависимостей и метка ИИ в коммите — готово, когда: Агент объяснил сводку лицензий пакетов (чужие фрагменты в вашем коде она не ловит); в git log -1 — Co-Authored-By.
- Обновить наставника и проверить день — готово, когда: SKILL.md лежит прямо в .claude/skills/mentor, в days есть файл этого дня, всё в коммите; /mentor 6 проверяет день.
