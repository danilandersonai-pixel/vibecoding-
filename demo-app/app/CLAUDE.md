# trainer-app

## Цель

Дневник тренировок для тренера и подопечных: подопечный записывает подходы (вес и повторы), тренер видит тренировки всех своих подопечных и их прогресс. Подробнее — в docs/idea.md.

## Стек

- Next.js 16 (App Router), TypeScript в строгом режиме
- Supabase: база, вход, RLS, хранилище файлов
- Vercel — публикация сайта
- Тесты: Vitest и Playwright

## Команды

- `npm run dev` — сайт на http://localhost:3000
- `npm run lint` — проверка кода

## Нельзя

- Коммитить секреты и ключи: они живут в .env.local, а он в .gitignore.
- Удалять или отключать тесты, чтобы проверки стали зелёными.
- Менять схему базы без моего подтверждения.
