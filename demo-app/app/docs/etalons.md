# Разбор эталонов

Три приложения, о которых я думаю, когда делаю своё. Названий не пишу: Эталон А, Эталон Б, Эталон В. Беру только публичное: описания и скриншоты на страницах приложений, справочные разделы, отзывы пользователей.

## Эталон А

Дневник тренировок для одного человека, тренера в нём нет.

- Сценарии: выбрать упражнение, записать подход (вес и повторы), запустить таймер отдыха, посмотреть историю.
- Экраны: календарь, тренировка дня, список упражнений, график по упражнению.
- Данные: упражнение, подход (вес, повторы), тренировка, дата.
- Жалобы из публичных отзывов:
  - на запись одного подхода уходит слишком много нажатий;
  - реклама прямо во время тренировки;
  - после смены телефона история пропала;
  - тренеру свои записи не показать.

## Эталон Б

Сервис для тренеров, которые ведут подопечных онлайн.

- Сценарии: тренер собирает программу и назначает её подопечному; подопечный отмечает выполненное; тренер смотрит отметки и пишет в чат.
- Экраны: список подопечных, конструктор программы, календарь подопечного, чат.
- Данные: тренер, подопечный, программа, упражнение с планом (подходы, повторы, вес), отметка «выполнено», сообщение.
- Жалобы из публичных отзывов:
  - цена растёт с каждым подопечным;
  - конструктор программы неудобный: одно и то же приходится повторять руками;
  - подопечные ставят галочку, а настоящий вес не пишут, и тренер не видит прогресса;
  - слишком много уведомлений.

## Эталон В

Приложение фитнес-клуба для его посетителей.

- Сценарии: записаться на занятие, открыть программу от клуба, посмотреть видео упражнения, отметить посещение.
- Экраны: расписание, программа клуба, видео упражнения, профиль с абонементом.
- Данные: абонемент, занятие, программа, упражнение, видео, посещение.
- Жалобы из публичных отзывов:
  - работает только в одном клубе;
  - программу под себя не изменить;
  - вес и повторы записать негде, есть только отметка «был»;
  - когда абонемент кончается, история тренировок пропадает.

## Что берём только как идею

Это шаги 1–2 чистой комнаты: только публичный материал, разобранный на сценарии, экраны, данные и жалобы. Кода эталонов я не видела, чужие тексты не копирую.

- Из А — идею журнала подходов с весом и повторами и график роста по упражнению.
- Из Б — связку «тренер назначает, подопечный выполняет, тренер видит результат».
- Из В — готовую тренировку как отправную точку, которую можно менять.

Названия, тексты, иконки, оформление и экраны один в один не берём. Дальше — моя спецификация своими словами, и собирать буду по ней, а не по эталонам.
