# demo-app — приложение тренера для видеоуроков

Здесь живёт приложение тренера, на котором показаны примеры в видеоуроках курса. Это не отдельный проект для разработки, а источник записей: каждая команда, её вывод, дифф и коммит в ролике взяты из настоящей работы над этим приложением.

- `sessions/` — шаги сессий работы над приложением, по одной сессии в файле (`s01-start.mjs`, `s02-sets.mjs`, …). Сессии идут цепочкой: каждая продолжает предыдущую (поле `from`).
- `app/` — исходники приложения в том виде, в каком их оставила последняя сессия (файлы из `git ls-files` после записи).
- Записи сессий — `course/video/sessions/<id>.json`, их проигрывают ролики.

## Правило: правится только записью

`app/` и записи `course/video/sessions/*.json` руками не правятся никогда. Если нужно другое приложение или другой вывод, меняются шаги в `sessions/*.mjs`, и вся цепочка записывается заново.

## Как перезаписать

Из папки `course/`:

```sh
node scripts/record-session.mjs
```

Рекордер по-настоящему проигрывает все сессии по порядку во временной папке: создаёт проект через `create-next-app`, ставит пакеты (кэш npm — `course/node_modules/.cache/session-npm`), выполняет команды и коммиты, запускает `npm run dev` и открывает страницу в Chromium. Запись идёт несколько минут. В конце рекордер пишет `course/video/sessions/<id>.json` и заменяет `app/`.

После перезаписи — проверка записей:

```sh
npx vitest run video/sessions
```

Перезапись в другой день может дать другие записи. У зависимостей, которые ставит `create-next-app`, версии записаны диапазонами `^` (`"eslint": "^9"`, `"tailwindcss": "^4"` …), поэтому npm возьмёт самые свежие подходящие версии: изменятся `package-lock.json`, хеши коммитов и строки вывода (число пакетов, предупреждения, время). Уроки ссылаются на id событий и диапазоны строк вывода, поэтому после перезаписи прогоните и тесты уроков — весь `npm test`.

## Что нужно на машине

- Свободный порт 3000: на нём работает `npm run dev` сессии. Тест рекордера (`scripts/session/record.test.ts`) и `npm test` тоже поднимают сервер на этом порту.
- Chromium из `/opt/pw-browsers` (Playwright берёт его сам, `playwright install` не нужен).
- Доступ к реестру npm: пакеты Next.js ставятся из сети.
